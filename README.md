An intelligent database reasoning Agent powered by Gemini 2.0 and LangChain. Enables multi-step SQL generation and complex reasoning through natural language, bridging the gap between raw data and actionable insights while increasing sufficiency.

The requirments can be seen in the requirments.txt

You can try the final Agent tool by running "sql.agent.py", but remember to run the terminal and set your Api key in advance

I did some testings through "gemini_usage.py" and "sql_agent_fake.py" when building the agent tool. If you want to try these scripts, yoou must create your own .env file and add your google Api key.
